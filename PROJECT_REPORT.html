1. Project Abstract & Scope

The AI Disaster Mapper is an AI-powered disaster management application designed to monitor, analyse, and visualise natural disasters such as floods, earthquakes, cyclones, landslides, forest fires, and droughts.

The system collects real-time and historical disaster-related data from various sources (USGS, NASA EONET, Open-Meteo) and displays affected locations on an interactive geographical map. Using Python, Machine Learning, and data analytics, the application analyses disaster patterns, identifies high-risk areas, and estimates potential disaster risks. It provides information about affected populations, damaged infrastructure, agricultural losses, and emergency assistance locations such as hospitals, rescue centres, and shelters.
