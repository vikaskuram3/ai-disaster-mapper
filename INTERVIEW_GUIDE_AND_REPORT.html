SECTION 2: TOP TECHNICAL QUESTIONS & EXACT INTERVIEW ANSWERS

Q1: What problem does AI Disaster Mapper solve?

Answer: During natural disasters, critical decision-making is severely hampered because data sources are fragmented across seismic agencies, weather bureaus, and hospital databases. AI Disaster Mapper unifies live real-time monitoring, AI risk forecasting, damage estimations, and emergency facility routing into a single centralized command center for disaster authorities.

Q2: How does your Machine Learning model work?

Answer: The model takes 12 physical and demographic inputs (rainfall, wind speed, ambient temperature, soil moisture saturation, slope angle, peak ground acceleration, vegetation dryness, population density, and infrastructure resilience). It uses an L2-regularized Ridge regression pipeline with feature normalization:
w* = (XᵀX + λI)⁻¹ Xᵀy
It outputs a continuous Risk Score (0-100), a vulnerability class (Critical, High, Moderate, Low), an estimated impact radius in km, and feature importance rankings for model explainability.

Q3: How does the emergency facility routing work?

Answer: I implemented the Haversine great-circle trigonometric formula to compute geodesic distances between any disaster epicenter and surrounding emergency facilities:
d = 2R · asin(√(sin²(Δlat/2) + cos(lat1)·cos(lat2)·sin²(Δlon/2)))
The algorithm computes distance in km, estimates emergency transit time in minutes based on terrain speeds, inspects current bed/shelter capacity, and ranks the top 5 closest facilities.

Q4: How did you solve the Windows AppLocker / DLL execution challenge?

Answer: On enterprise Windows environments, security policies (WDAC/AppLocker) block compiled Cython binary DLLs (.pyd) from running in user AppData folders. To guarantee 100% portability, I engineered a pure-NumPy regularized AI engine using matrix inversion (np.linalg.pinv). It runs with zero binary DLL dependencies, is completely immune to AppLocker blocks, and delivers identical mathematical predictions.

Q5: What SQL concepts and advanced queries did you implement?

Answer: I built an SQLite relational database with indexed tables and utilized Window Functions including RANK() OVER (PARTITION BY disaster_type ORDER BY severity_score DESC) to rank the most severe hazards in each category, DENSE_RANK() OVER for regional vulnerability exposure rankings, and running capacity sums.

SECTION 4: DAMAGE ASSESSMENT & EMERGENCY RELIEF FORMULAS

  • Exposed Population: P_exposed = π · r² · Population_Density
  • Displaced Citizens: P_displaced = P_exposed · α_hazard · (Severity / 100)^1.8 · (1.2 - Resilience)
  • Inundated/Parched Cropland: Crop_ha = π · r² · Agricultural_Density · β_hazard · (Severity / 100)^1.8
  • Economic Loss ($M): Loss_USD = (P_exposed · Cost_Per_Capita · (Severity / 100)^1.8 · Vuln) / 1,000,000
  • SPHERE Drinking Water Supply: Water_Liters = Displaced_People × 3.0 Liters/person/day × Planning_Days
  • SPHERE Food Rations: Food_KG = Displaced_People × 1.5 KG/person/day × Planning_Days
